#  RecSystem – система рекомендаций

**RecSystem** – это веб-приложение для любителей просмотра фильмов, сериалов, аниме, в будущем возможно для читателей книг.  
Система позволяет взаимодействовать с контентом: лайкать, дизлайкать, добавлять в любимые.  
Проект ориентирован на поиск нового смежного контента для просмотра на основе предпочтений пользователя.

---

## ✨ Функциональность

-  **SSO** – Авторизация пользователя
-  **Catalog** – управление каталогом(контеном), позволяет получать/редактировать контент. Загрузка его производится с внешнних сервисов. Получение тегов для более лучшей системы рекомендаций(in_progress)
-  **Notification** – Сервис отправки уведомлений пользователю на почту, получает сигналы от SSO через kafka
-  **Recommendation** – Система рекомендаций. Позволяет взаимодействовать с контентом (like, dislike, add_to_favorites). Создаёт рекомендации пользователю на основе его предпочтений(in_progress). Также имеется ИИ-инструмент который может помочь с рекомендациями также на основе предпочтений или по отдельному запросу.
- 🛠 **Api-gateway** – точка объеденения всех компонентов (in_progress) 
- 🔐 **Авторизация и токены** – хранение и обновление **JWT** через **Redis**

---

## 🏗 Используемый стек

- **Go (Gorilla, gRPC, Protobuf)** – backend
- **PostgreSQL** – основная база данных
- **Redis** – хранение и обновление JWT-токенов
- **Kafka** – система уведомлений при регистрации и логине пользователей
- **Docker & Docker Compose** – контейнеризация и запуск приложения
